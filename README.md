# 深渊牌局：破碎轮回

一款暗黑风格的 Roguelike 卡牌游戏，灵感来自《杀戮尖塔》。

## 运行方式

本项目为纯前端项目，无需构建步骤，使用原生 JavaScript ES Modules 开发。

### 方法一：使用 Python 启动本地服务器

```bash
cd /workspace
python3 -m http.server 8080
```

然后在浏览器中打开 `http://localhost:8080`

### 方法二：使用 Node.js 启动本地服务器

```bash
npx serve /workspace
```

### 方法三：直接打开

部分浏览器支持直接打开 `index.html`，但 ES Modules 需要服务器环境才能正常工作。

## 游戏特色

- **4 个独特角色**：铁甲战士、奥术行者、暗影之刃、圣言牧师，各有独特机制
- **4 幕关卡**：幽暗地牢 → 冤魂之殿 → 熔岩腹地 → 深渊王座
- **Roguelike 地图**：每局随机生成地图，包含战斗、精英、事件、商店、营火、宝箱等节点
- **200+ 张卡牌**：攻击、技能、能力三大类型，普通/罕见/稀有三种稀有度
- **30+ 种遗物**：提供被动增益，改变游戏策略
- **20 种药水**：一次性使用的战斗道具
- **20 个随机事件**：做出选择，承担后果
- **20 级飞升难度**：逐步解锁更高挑战
- **种子系统**：输入种子可重现同一局游戏

## 操作说明

- **主菜单**：开始新游戏、继续游戏、输入种子、查看统计
- **角色选择**：点击角色卡片选择，可调整飞升难度
- **地图界面**：点击发光的可用节点移动
- **战斗界面**：
  - 点击手牌中的卡牌使用
  - 需要指定目标的攻击牌：先点击卡牌，再点击敌人
  - 点击"结束回合"按钮结束玩家回合
  - 点击药水图标使用药水
- **营火**：选择休息（恢复生命）或锻造（升级卡牌）
- **商店**：购买卡牌、遗物、药水，或付费移除卡牌
- **事件**：阅读事件描述，选择一个选项
- **宝箱**：拾取或跳过遗物

## 项目结构

```
src/
├── core/           # 核心系统
│   ├── game.js     # 游戏状态管理
│   ├── rng.js      # 种子随机数生成器
│   └── events.js   # 事件系统
├── systems/        # 游戏系统
│   ├── battle.js   # 战斗系统
│   ├── map.js      # 地图生成
│   └── save.js     # 存档/进度系统
├── ui/             # 用户界面
│   └── renderer.js # 渲染器（所有屏幕）
├── data/           # 游戏数据
│   ├── cards.js    # 卡牌数据
│   ├── enemies.js  # 敌人数据
│   ├── relics.js   # 遗物数据
│   ├── potions.js  # 药水数据
│   ├── events.js   # 事件数据
│   └── characters.js # 角色数据
├── utils/          # 工具函数
│   └── helpers.js  # 通用工具
├── audio.js        # 音频管理
└── main.js         # 入口文件
styles/
└── main.css        # 全局样式
```

## 技术栈

- 原生 JavaScript (ES Modules)
- HTML5 + CSS3
- Web Audio API（音效）
- localStorage（存档）
- 无外部依赖
